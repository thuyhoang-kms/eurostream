## Findings

- `src/eurostream/bus/kafka.py:99` — KafkaProducer.produce returns a fabricated RecordMetadata(partition=0, offset=0) and delivery failures are only logged in the callback, so failed sends are silently lost.

- `src/eurostream/bus/sqlite.py:179` — SqliteConsumer.commit persists self._pos, which poll() has already advanced, and close() also commits, so closing can commit past an unprocessed record.
